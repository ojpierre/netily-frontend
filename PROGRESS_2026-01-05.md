### Router Authentication System
Implemented a secure authentication flow for connecting MikroTik routers to Netily:

#### How It Works:
1. **Router created** → System generates unique `auth_key` (e.g., `RTR_0001_XY7K_AUTH`)
2. **Admin copies script** from Scripts tab
3. **Run on MikroTik** → `/tool fetch url="https://api.netily.io/api/v1/routers/auth?key=RTR_XXX_AUTH" mode=https`
4. **Backend receives request** → Validates key, captures router's IP address
5. **Router marked authenticated** → Updates `is_authenticated=true`, `authenticated_at=now()`

#### Scripts Tab Features:
- **Authentication script** always visible at top with blue styling
- Shows authentication status badge (green if authenticated)
- Displays last authenticated timestamp
- **Copy to Clipboard** button for easy copying
- Instructions for running in MikroTik terminal
- Other custom scripts shown below with run/edit/delete actions

## API Endpoints Used

### PayHero Integration:
```
POST /billing/payments/initiate/
GET  /billing/payments/{id}/
GET  /billing/payment-methods/?is_active=true
```

### Request Format:
```json
{
  "amount": "1000.00",
  "external_reference": "INV-0001",
  "channel_id": 1,
  "phone_number": "254712345678"
}
```

### Response Format:
```json
{
  "status": "success",
  "payment_id": 123,
  "payhero_response": {
    "status": "pending",
    "checkout_request_id": "ws_CO_...",
    // or payment_url, paybill_number, till_number, bank_details
  }
}
```
