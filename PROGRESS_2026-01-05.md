## 1. Router Management Revamp

### Router Detail Page (`app/admin/routers/[id]/page.tsx`)
Completely revamped the router detail page with a new 8-tab structure based on competitive analysis:

| Tab | Features |
|-----|----------|
| **Info** | System resources (CPU, memory, disk), uptime monitoring, connection stats, quick actions |
| **Script** | MikroTik configuration script with single-line display, dark terminal UI, one-click copy |
| **Hotspot** | Hotspot IP configuration, DHCP pool settings, DNS settings |
| **Settings** | API credentials, connection settings, polling intervals |
| **Backups** | Backup management, restore points, scheduled backups |
| **Bandwidth** | Real-time bandwidth monitoring, interface statistics |
| **Firewall** | Firewall rules management, NAT configuration |
| **Edit** | Router details editing (name, IP, credentials) |

## 2. PayHero Payment Gateway Integration

### New Types (`lib/types.ts`)
```typescript
// PayHero response structure - handles all channel types
interface PayHeroResponse {
  status?: string
  checkout_request_id?: string  // STK Push
  payment_url?: string          // Payment Link
  paybill_number?: string       // Paybill
  till_number?: string          // Till
  account_number?: string
  bank_details?: {              // Bank Transfer
    bank_name?: string
    account_name?: string
    account_number?: string
    branch?: string
  }
}

// Request/Response interfaces
interface PaymentInitiateRequest { ... }
interface PaymentInitiateResponse { ... }
```

### Admin API Methods (`lib/admin-api.ts`)
| Method | Endpoint | Purpose |
|--------|----------|---------|
| `initiatePayment()` | `POST /billing/payments/initiate/` | Unified payment initiation |
| `pollPaymentStatus()` | `GET /billing/payments/{id}/` | Check async payment status |
| `getActivePaymentMethods()` | `GET /billing/payment-methods/?is_active=true` | Fetch available methods |

### Customer API Methods (`lib/api.ts`)
Same methods added for customer-facing portal:
- `getInvoices()`
- `getActivePaymentMethods()`
- `initiatePayment()`
- `pollPaymentStatus()`

### Admin Payments Page (`app/admin/payments/page.tsx`)

#### New Features:
- **"Pay Now" button** - Primary action in toolbar for unified payments
- **"Manual Entry" dropdown** - Contains legacy M-Pesa STK Push and Bank Transfer
- **Unified Payment Dialog** with:
  - Amount input
  - Payment method selector (fetches from API)
  - Phone number field (required for STK Push)
  - Invoice/Reference field

#### Response Handling:
| Channel | UI Response |
|---------|-------------|
| **STK Push** | "Check your phone" message + automatic polling |
| **Payment Link** | Opens payment URL in new tab |
| **Paybill** | Shows paybill number, account number, amount |
| **Till** | Shows till number and amount |
| **Bank** | Shows bank details (name, account, branch) |

### Customer Invoices Page (`app/dashboard/invoices/page.tsx`)

#### New Features:
- **"Pay Now" button** on each unpaid invoice row (green, prominent)
- **Payment Dialog** with same functionality as admin page
- Payment method selection
- Phone number input
- All PayHero response types handled
- Automatic polling for async payments

## API Endpoints Used

### PayHero Integration:
```
POST /billing/payments/initiate/
GET  /billing/payments/{id}/
GET  /billing/payment-methods/?is_active=true
```

### Request Format:
```json
{
  "amount": "1000.00",
  "external_reference": "INV-0001",
  "channel_id": 1,
  "phone_number": "254712345678"
}
```

### Response Format:
```json
{
  "status": "success",
  "payment_id": 123,
  "payhero_response": {
    "status": "pending",
    "checkout_request_id": "ws_CO_...",
    // or payment_url, paybill_number, till_number, bank_details
  }
}
```
